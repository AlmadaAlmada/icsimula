# Changelog

Formato baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e [SemVer](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-10-26

### Adicionado

- Simulador de investimentos com juros compostos e aportes mensais.
- Simulador de financiamento comparando SAC x Price, com tabela de parcelas.
- Planejador de metas (aporte mensal necessário).
- Espaços reservados para anúncios.
- Pipeline CI/CD com qualidade, testes, segurança, build, deploy no GitHub Pages e smoke test.
- Monitoramento agendado com abertura automática de issue em caso de indisponibilidade.
- Dockerfile multi-stage com Nginx não-root e publicação no GHCR.
